<summary><b>⬡ &nbsp;GlycoTwin — Biological Simulation via Neural ODEs</b></summary>

<br/>

The system models complex dynamic biological states by combining traditional differential equations with deep learning, allowing for more accurate continuous-time series modeling.

<details>
<summary><b>⬡ &nbsp;Dino-AI — Neuroevolution Game Agent</b></summary>

<br/>

An AI agent built to master a custom Pygame clone of the classic Chrome Dinosaur game. Instead of traditional reinforcement learning, Dino-AI utilizes neuroevolution and genetic algorithms to iteratively breed generations of neural networks. The networks mutate and crossover based on fitness scores to eventually learn perfect timing and hurdle clearance.

| Attribute | Detail |
|---|---|
| **Stack** | Python, Pygame, Numpy |
